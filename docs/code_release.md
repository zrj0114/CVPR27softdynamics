# 初始流程与第一创新点代码整理核对

本次整理范围为初始 real2sim、共享资产、敏感度教师与预训练、冻结模型加权参数辨识，以及对应评测。使用已完成实验的实现，不包含后续动力学代理模型实验。数据、资产、标签和模型权重不上传。

## 保留与补齐

- 保留旧牛角包的原始相机解析、首帧体积构建、共享 canonical asset、逐段首帧配准、接触及确定性 MPM。
- 补入 `runtime/prepare_legacy.py`：相机和体积函数原样提取，仅新增显式路径和已标定动作打包入口；不重做 Gaussian 训练或夹爪标定。
- 保留清洗版数据的独立指垫接触、52 维动作、完整状态有限差分教师、CausalMotion 预训练和四个独立预测头。
- 保留冻结模型的四列交互权重、三档对照、按参数轮换的连续 CMA-ES、候选预算与查询评测。
- 补齐 CMA-ES 准备阶段的代码快照：之前脚本将 runtime 指向 `code/runtime`，但单独运行准备入口不会创建该目录。现在准备阶段实际复制源码、核对旧物理源文件，并从快照启动工作进程。增加回归测试；没有修改 CMA 目标或参数更新公式。
- 移除评测入口默认绑定到某台机器的 EMPM 路径，改为显式 `--empm`；补充依赖、命令行入口和复现步骤。

旧接触和清洗版接触的区别保留在 README 与各自文档中，不能把两套输入互换后仍声称复现同一基线。

## 使用已有第一创新点输出

已有完整预训练运行目录时，保留其中 `config.json`、`selection.json`、`objects/`、`labels_v1/` 和 `training/full/` 的输入依赖。从首页的 `recovery_data --mode prepare --pretrain ...` 开始即可使用现有模型；无需先训练其他网络。

后续模块应读取这里实际冻结的模型、拟合参数、共享 asset 和运行版本，再生成它自己的教师数据。旧牛角包手工配置和第一创新点输出是两个不同来源，不应互相冒用。
