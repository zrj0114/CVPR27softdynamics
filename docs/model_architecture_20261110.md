# 最新模型架构（2026-11-10）

主入口是 `elastic_world_train.py` 的 `StepWorld`，继承 `JointWorld` 并共享 `SharedWorldModel` 编码器。配置以 [`teacher50_current.json`](../configs/teacher50_current.json) 为准。`shared_world_model.json` 等文件保留历史实验配置。

## 输入编码

| 编码器 | 维度 | 输入 |
|---|---|---|
| State MLP | 31 → 256 → 256 | 24 维状态接口、3 维参考位置、离地高度、物体尺度、时间间隔、表面标记 |
| Pad MLP | 46 → 256 → 256 | 28 维相对位置／夹爪运动特征，追加 18 维接触几何、法向、相对速度等特征 |
| Material MLP | 2 → 256 → 256 | `log(E/3500)` 与 `(ν−0.27)/0.12` |

三个编码器均为 Linear → SiLU → Linear。当前 `kinematic_only=true`、`direct_displacement=true`：24 维接口中的 F、C 通道置零后进入编码器，实际状态信息来自位置、当前速度和参考几何，没有学习内部形变记忆。

每个节点分别编码有效指垫，使用 `finite_pad_grid_swept.v1` 门控并按局部作用范围汇总。范围考虑垫面平移、旋转、节点当前运动和二次 MPM 插值支撑。单夹爪任务的其余指垫槽位无效。

## 局部图 Transformer

512 个动力学节点，各连接参考几何中的 24 个邻居；4 层、256 维、4 个头，每头 64 维。每条边的 9 维特征为：

`[x_j − x_i, v_j − v_i, x_ref_j − x_ref_i]`。

每层执行：

```text
LayerNorm + 材料条件缩放/平移
  → 局部 Q/K/V 注意力（边特征影响 logits 和 value）
  → 输出投影 + 残差
  → LayerNorm → Linear 256→512 → SiLU → Linear 512→256
  → 残差
```

Material MLP 的输出加到节点特征上，同时经每层独立 `256→512` 线性层产生 scale、shift，调制为 `LayerNorm(h) * (1 + 0.1*tanh(scale)) + shift`。无效观测在输入、邻居注意力及池化中均有掩码。

## 输出头

**逐点动力学头**：LayerNorm → Linear 256→256 → SiLU → Linear 256→3。输出经尺度还原的区间速度，并更新位置。按物理单位表示：

`x̂_(t+1) = x_t + Δt · v̂_interval`。

实现内部按物体尺度归一化位置，速度还包含 `DT_REF=1/30` 的尺度，所以实际乘 `Δt/DT_REF`。F、C 字段原样携带，不是预测的物理内部状态。

**E 与 ν 敏感度头**：各为 LayerNorm → Linear 1024→128 → SiLU → Linear 128→1 → Sigmoid。观测上下文默认在交互前、交互中、释放后各取 2 帧，每帧最多 128 个点。逐帧复用编码器后：

1. 点维 mean/max 拼接，得到每帧 512 维；
2. 时间维 mean/max 拼接，得到交互 1024 维；
3. 两个独立头输出 `c_E, c_ν`。

时间维使用池化，没有时间 Transformer。两个任务共享权重但输入不同；动力学转移不读取评分任务的未来观测上下文。

当前配置总参数 **3,200,789**：动力学网络 **2,934,035**，两个敏感度头合计 **266,754**。

## 训练和搜索

训练只接受一个转移的样本。默认动力学损失包含位置误差和 0.2 倍归一化速度误差，再加 0.1 倍敏感度评分 MSE。评分标签使用仅从训练集校准的尺度映射到 `[0,1]`。共享骨干和输出头从头联合优化。

每步读取给定当前状态，预测不反馈到下一样本。默认 40,000 次更新，按单步验证误差选择 `best.pt`，另保存 `latest.pt`。

搜索固定网络，多段交互共享 E、ν。敏感度评分在参考参数处计算一次，各参数在交互维独立归一化后固定；两个参数分别汇总对应列的梯度。最终候选仍按未加权平均观测误差排名。评分不是材料回归值，也不是预测正确概率。

## 当前边界

已实现有限垫面动作范围、补全动作契约、逐参数加权搜索、无效点掩码、完整敏感度验证、教师加速、矩形网格和细网格重试。
