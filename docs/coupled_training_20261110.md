# 连续动力学与联合材料响应训练

本版将材料条件化空间编码器扩展为因果连续预测模型。教师 B、动作契约、材料范围与对象划分沿用已核对版本。训练使用 2,985 条训练轨迹、320 条验证轨迹；280 条已完成测试轨迹不参与训练或选模。

## 网络

总参数 3,632,614，其中动力学与逐点记忆 3,328,787，时间评分及联合头 303,827。

- 空间骨干：512 个动力学节点、24 邻居、4 层 256 维／4 头局部图注意力，E、ν 条件调制。
- 动力学记忆：逐点 256 维 GRU，以 `h + 0.1 * memory` 输入原来的区间速度头。最多 3 个过去帧初始化记忆；预测段只读当前预测状态、给定动作和材料参数。
- 联合评分：教师定义的 6 个有序窗口，使用教师的最多 256 个对应观测点。空间 mean/max 拼接到 512 维；相对时间、间隔和三阶段标记经 5→32→16 MLP 编码，与空间特征共同输入 128 维 GRU。序列 mean/max/last 拼接为 384 维，联合头 384→128→3。
- 两个输出经 softplus 得到以训练集 tau 为单位的正响应强度，第三个经 tanh 得到相关性 rho。由此构造正半定的 2×2 响应 Gram 矩阵。评分 `S/(S+tau)` 不表示概率。

学习记忆不是物理 F 或 C，当前模型没有硬接触或体积守恒保证。两种任务的输入独立；评分序列中的未来观测不会进入动力学预测。

## 损失与阶段

总损失按固定权重求和：

| 项 | 权重 | 定义 |
|---|---:|---|
| 连续动力学 | 1 | 3 mm 尺度的位置 MSE + 0.2 倍归一化速度 MSE |
| 第一帧动力学 | 0.2 | 每个短预测段的第一个转移 |
| 敏感度评分 | 0.1 | 教师有效 S 列映射后的 MSE |
| 相关性 | 0.025 | 两列均通过数值审计且响应非零时的 rho Smooth L1 |
| 局部响应 | 0.1 | 固定过去记忆、当前状态和动作的有符号有限差分，与教师 J 对齐 |
| 两分支一致性 | 0.05 | 预测 J 的强度／相关性与联合头输出一致 |
| 成对绝对轨迹 | 0.1 | 材料配对的两条轨迹都接受位置／速度监督 |
| 成对轨迹差 | 0.2 | 两组材料轨迹的有符号差值，按真实响应能量与噪声底归一化 |

前 1,000 次更新预测 1 步；之后分别在第 1,001、4,001、10,001 次更新开始使用 4、8、16 步。每步抽取 2 个对象／阶段均衡的动力学样本与 1 个评分样本。每 8 次更新加入局部响应及一致性，每 16 次更新加入材料配对。零损失项表示该更新未抽取对应额外监督，不表示忽略该物理量。

局部扰动使用教师坐标 `q=[log(E/3500), (nu-.27)/.2]`，按每列实际审计半径计算有限差分；点 ID 顺序、可见终点、毫米单位、点数和阶段权重均对齐教师。状态来自合成点轨迹；评分编码器另行使用观测可见性掩码。局部状态记忆根据名义材料的过去状态计算一次，在所有参数探针之间固定。

配对只能来自相同交互、初始状态、几何、动作、时间轴、物理来源、模拟域及固定物理参数，仅 E、nu 变化。轨迹从共同的第零帧完整推进；前 1,000 次更新前缀上限 32，随后至第 4,000 次更新上限 128，再放开到完整交互。长前缀只对最后 16 个间隔进行权重反向传播，之前的状态仍然由模型预测，无教师状态重置。默认推理 `forecast(..., gradients=True)` 不截断材料梯度。

每个材料配对的差值是有限材料变化的响应，不是局部无穷小 Jacobian；它不替代固定状态教师 J。

## 验证的范围

每 500 步以及第 1 步验证：每个验证交互固定选择一个材料变体，按元数据选择各阶段的 16 步窗口；同时报告第一步误差、静止和恒速基线。联合评分按对象固定抽样，局部有符号响应与完整材料配对分别检查。

每个验证对象选一个非参考材料，以受力和释放阶段的两个 8 步窗口进行 12 步、单起点 E／nu 联合优化，作为固定预算的材料恢复诊断。真值仅计算恢复误差，不输入候选初始化或目标函数。此诊断不是完整下游搜索，不代表原始 MPM 复演通过。

选模固定采用 `16步位置误差/3mm + 0.1*配对响应MSE + 0.1*局部响应MSE + 0.1*归一化参数恢复误差`。测试集不用于选择配置或检查点。历史单步模型、连续预测模型和联合模型的完整消融结果尚不能由本次代码检查替代。
