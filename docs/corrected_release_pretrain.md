# 清洗版 Deform360 的离线标签与预训练

本流程组合读取官方 processed 物体观测和 `fixed121_camextr_20261020_v1` 的独立指垫轨迹。共享源数据只读，所有输出写入新的运行目录。

```bash
pip install -e '.[physics,deform360]'
python -m softdynamics.shared_data --select-only \
  --source /data/shared/deform360_softbody_10ep_20261019/processed \
  --corrected /data/shared/deform360_softbody_fixed121_camextr_20261020_v1 \
  --config configs/corrected_release_pretrain.json --output /path/to/new/run
python -u -m softdynamics.shared_pipeline --root /path/to/new/run \
  --gpus 1 3 4 2 5 6 7 --prep-workers 4
```

调度器可在后台运行，退出后用同一命令续接。`jobs.json` 记录进程与任务，`status.json` 记录阶段。它不会停止其他进程；空闲显存不足或磁盘剩余不足 5 GiB 时等待。指定卡上本用户原 EMPM 任务的短期重叠被允许，其他用户的大显存任务不会被当作可共享任务。

## 输入筛选与资产

- 22 个物体、220 段源交互。第一道门槛是现有夹爪质量筛查和操作前后至少两个点云帧，得到 148 个候选；这不是最终训练样本数。
- 沿用初帧 Gaussian 凸包内 3 mm 采样、初帧多视角轮廓雕刻，再细分到 1.5 mm 的体积构建方法。此次投影使用修正相机。
- 每个物体一个 canonical asset；参考段取该物体最早的候选 episode。其他段仅用各自首帧配准初态，保留正形变梯度与质量。配准失败单独记录。
- 初帧体积、正映射、地面约束和 12 mm 初帧配准误差分别检查。不会为通过筛查而把动态观测写回初态。
- 体积至少包含 512 个粗网格单元，三个方向各至少覆盖 3 个单元；按每粒子 1 KiB 估计的初始化内存不得超过 8 GiB。门槛适用于全部物体，不沿用牛角包特定的粒子数量上下限。
- 点云按原始帧号对齐；每段缺少末尾 5 帧。选取最多 512 个首帧匹配视觉 Gaussian、且有至少两个视觉相机支持的点，保留固定行号及后续可见性。没有读取触觉输入；官方轨迹内部更早的重建／正则化来源仍属于上游数据约定。

密度 100 kg/m³、地面 Y=-0.01 m 和初态零速度沿用既有实验假设，未作为真实测量值宣称。首帧被假定为弹性参考形状；重力预应力没有被独立反演。

## 修正指垫接触

`world_from_pad_center` 的 X 轴为面法向，Y/Z 为 64/25 mm 的两边。左侧内法向 +X、右侧 -X。新 `pad_contact_kernels.py` 使用相同的单侧 Coulomb 冲量公式，接触范围改为交付的矩形中心坐标；所有物质都可与任一侧接触，不用未来物体位置选材料标签。

两端动作都有效才启用该侧运动；缺测不插值。完整动作时间轴保持启用，metadata 不作为接触开关。仅数值网格范围由初态和标注操作区间的夹爪包围盒确定，初始留 75 mm 余量。底层 G2P 会在距边界两个网格处截断位置，因此检查器将触及该范围的 rollout 判为失败，绝不接纳其标签。若状态有限且形变梯度行列式仍为正，调度器保留失败输出，依次扩大到 150/250 mm 余量重算，最多三次。网格间距保持 3.125 mm，立方网格上限为每轴 384 个单元。

神经网络动作改为 52 维：4 个独立指垫，每个 3×4 位姿和有效标志。位置以初始物体中心和尺度归一化，保留指垫之间的间距与其相对物体的位置。旧 28 维 EEF 模型仍可加载。

## 教师

四个目标为 E、ν、地面摩擦和速度衰减率，夹爪静／滑动摩擦固定。首批保留之前牛角包实验的局部参数范围；当前模型不声称覆盖任意材料参数范围。

每个候选 episode 两个已知参数的合成真值 rollout，每条真值轨迹对应五个查询工作点。完整连续模拟从原初态开始。每个 metadata 阶段选两个有观测支持的端点，取阶段内的 25%/75% 分位，保存其前一帧的完整物理状态。窗口选择不依赖教师响应。

从同一个状态固定其他参数、只扰动一项，测下一观测间隔末端的三维跟踪点变化。使用两组中心差分步长检查列向量一致性，失败项按预定更小步长复查；25% 容差仍不通过的轴保存 NaN 与有效掩码。重复未扰动分支必须逐字节得到同一动态状态。所有真值和扰动使用同一 CFL 安全时间步上限。

J 的四列范数产生独立敏感度 S。前／中／后阶段权重为 0.1/0.45/0.45。相关矩阵仅用于诊断，没有 Schur 补、softmax 或“每次交互只能敏感一个参数”的限制。这里估计的是条件于完整中间状态的局部偏导，不是整段历史的总导数。

与标签配套的 `input.npz` 必须来自同一已知真值的合成运动；不同真值不会共用一份真实运动输入。

## 训练与评估

划分在标签生成前按物体冻结。验证物体为 047、090、120、185；测试物体为 048、095、125、187；其余为训练物体。同一物体全部 episode、真值和工作点同组。

首批固定为 046、057、121、120、048 各最早两个候选 episode。首批离线标签任务全部结束后，先训练一个 pilot；全量标签随后继续生成，完成后再训练完整模型。失败任务保留，不用后来更容易的交互替换 pilot 成员。

先在训练物体的真实／合成视觉运动上训练 CausalMotion，验证物体选择 checkpoint，然后冻结编码器训练四个独立头。运动验证每段取八个均匀分布的预测窗口，覆盖交互过程。测试物体不用于选择 checkpoint。监督目标 `log1p(S/tau)`，`tau` 仅从训练标签估计；推理给出 `S/(S+tau)`。

`training/pilot` 与 `training/full` 各包含 `model.pt`、`encoder.pt`、`report.json`、预测和行号对应表。报告同时给出置信度 MAE、训练集常数基线，以及在同一物体／真值／查询工作点下跨交互比较的成对准确率和 Spearman。模型选择未使用测试物体结果。

这些指标评估敏感度预测；有针对性的参数优化收益需要另行进行固定预算的物理恢复比较。
